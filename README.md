# Orion Mobile

Expo, React Native, and TypeScript mobile app for Orion.

## Quick Start

1. Install dependencies.

   ```bash
   npm install
   ```

2. Start the app.

   ```bash
   npm run start
   ```

## Common Commands

- `npm run android` launches the Android app locally.
- `npm run ios` launches the iOS app locally.
- `npm run web` starts the web target.
- `npm run lint` runs linting.

## Repo Layout

- `app/` Expo Router entry points and screens.
- `src/` shared app logic, services, and analytics.
- `components/` reusable UI and screen components.
- `assets/` static images and media.
- `openspec/` workspace specs, backlog, and change proposals.
