# Changes Index

Use this folder for proposed modifications that are not yet part of the current specs.

## Recommended structure

- One folder per change.
- A proposal document that explains the intent and scope.
- Supporting artifacts such as design notes, task lists, or delta specs.

## Workflow

1. Create a change folder.
2. Document the proposal and its impact.
3. Break the work into tasks when implementation starts.
4. Implement incrementally.
5. Merge the resulting behavior back into `openspec/specs`.
